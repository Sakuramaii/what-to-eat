## 与应用一致的指标用语

| 指标 | 从低到高的原有档位对应文字 |
| --- | --- |
| 距离 | 远、较远、适中、较近、近 |
| 价格 | 贵、较贵、适中、较便宜、便宜 |
| 味道 | 不好吃、不太好吃、一般、好吃、很好吃 |
| 饭量 | 少、较少、适中、较多、多 |
| 吃完速度 | 慢、较慢、适中、较快、快 |

饭量和速度按本次需求取舍，不预设越多、越快越好。五项文字档位来自个人评价；速度不代表出餐或排队速度。区间写法用于展示，10–15元表示大于10元、不超过15元，不是实时报价。
